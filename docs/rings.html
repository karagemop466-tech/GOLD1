Findings

  • Weight (grams) is published by no retailer reviewed — the column is blank on every row (Flag F1). Ask the seller in writing; verify independently.
  • Solid-gold language: Mejuri states '14k solid gold' explicitly; Tiffany/Cartier/BE/BN state karat + metal. FTC Guides (16 CFR §23.3) prohibit describing surface-coated or hollow products as solid gold.
  • Return policies differ materially — Tiffany's page shows conflicting return text (Flag F2); verify before purchase.
  • James Allen → Blue Nile migration means any JA price in circulation may be stale (Flag F8).
