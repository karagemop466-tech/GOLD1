Sources

A value is only allowed on this site if it appears in one of these primary sources. Round-ups, affiliate lists, review aggregators and search snippets are never used for a number.

No hallucinations — the rule this whole project runs on

Every price, karat and weight below is copied from the seller's own official product page or feed and linked on the same row. Nothing is estimated, averaged, inferred or remembered. If a value was not confirmed on an official source it is shown as — unverified and listed on the Flagged for review page. Every build is mechanically verified by automated anti-hallucination and security passes (S01–S19 + A01–A10). Price snapshots are not live quotes: the latest product-page re-read was 2026-10-23; retailer prices and gold spot can change, so verify the linked official source immediately before buying.
